# 人人 AI 通识课 · HTML 互动课程

> **新时代的工具，动手去用。**
> 一套面向 12–50 岁普通人的 AI 科普互动课：不写代码、不装软件、双击就能看。

## 🔗 直接访问

- **在线版（手机 / 电脑都能直接打开）**：<https://481556750.github.io/AIClass-Rico/>
- **GitHub 仓库**：<https://github.com/481556750/AIClass-Rico>

> 分享给朋友就用在线版链接；没网时仍然可以双击 `index.html` 本地打开。

## 这是什么

21 节互动网页课，从「AI 到底是什么」讲到「用想象力做出作品」，每节课都有得玩、有得测、有得做。

| 板块 | 内容 |
| --- | --- |
| 🚀 导学课 | AI 是新时代的工具，关键看谁在用 |
| 🤔 模块一 | AI 到底是什么（猜词王 / 训练 / 家族 / 幻觉） |
| 🛠️ 模块二 | 开始用 AI（DeepSeek 从入门到顺手） |
| 🎨 模块三 | 玩创作（画图 / 故事 / Agent / 作品实战） |
| 🛡️ 模块四 | 怎么防坑（幻觉 / 隐私 / 骗局） |
| 🚴 模块五 | 人和 AI（协作姿势 / 结业计划） |

## 怎么打开

- **最简单**：双击 `index.html`，浏览器直接打开（断网也能用）。
- 或者起个本地服务：`python -m http.server`，再访问 `http://127.0.0.1:8000`。

> 说明：为了让 `file://` 双击也能跑，课程数据、题库都写成了 `.js` 文件（不用 fetch 加载 JSON）。

## 目录结构

```
AIClass/
├─ index.html                 首页 · 课程地图
├─ lessons/                   每课一页
│  ├─ lesson-00.html          导学课
│  └─ lesson-01.html          第 1 课
├─ assets/
│  ├─ css/base.css            设计系统（深浅色 / 三档字号 / 组件样式）
│  ├─ js/course-data.js       课程地图数据
│  ├─ js/app.js               导航 / 进度 / 主题 / 小艾 / 打卡
│  └─ js/components.js        互动组件（测验 / 猜词 / 段位测试）
└─ 课程方案.md                 完整课程方案 v2
```

设计原则：**零依赖**（无框架、无 CDN、无构建工具）、纯静态、离线可用。
